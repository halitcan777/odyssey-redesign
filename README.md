# Редизайн сайта ГК «Одиссей» (Пермь)

Прототип нового сайта группы предприятий безопасности: охрана, стрелковый тир, учебный центр, полиграф.
**Живая версия:** https://halitcan777.github.io/odyssey-redesign/ · старый сайт: gpodyssey.ru

## Прочитай перед работой

1. **ДИЗАЙН-ПРАВИЛА.md** — палитра, отступы, типографика, бенто, взаимодействия. Отступать от правил можно только по слову заказчика. Правка в одном блоке применяется ко всем блокам той же логики.
2. **ПЛАН-МНОГОСТРАНИЧНИК.md** — структура сайта и порядок работ.
3. Весь контент (цены, тексты, телефоны) — только реальный, со старого сайта. Ничего не выдумываем. Если материала нет — плейсхолдер «НУЖЕН МАТЕРИАЛ: …» (правила §5).

## ⚠️ Регламент совместной работы (мы + кореша, чтобы ничего не слетало)

1. **Перед началом работы — всегда** `git pull --rebase origin main`. Перед уходом — закоммитить и запушить.
2. **Страницы правятся РУКАМИ в HTML.** Генератор `build_pages.py` ЗАМОРОЖЕН — его запуск перезапишет все ручные правки.
3. Новые тексты прогонять: `python3 typograf.py <файл.html>` (безопасен для разметки).
4. Стили — только в `styles.css` и только через токены (`var(--ink)` и т.д., темы!). **Никаких инлайновых margin/размеров** — инлайн перебивает мобильные медиа-правила (уже ловили баг).
5. После пуша Pages НЕ пересобирается сам: `gh api repos/halitcan777/odyssey-redesign/pages/builds -X POST`.
6. Проверка после правок: обе темы + scrollWidth на 390 и 1440 (см. §7 дизайн-правил).
7. Конфликт в файле — не решать «выбрать свою версию», а совместить правки; спорное — в чат.

## Конвейер правок

```
правка контента → pages_content.py   (или index.html руками)
python3 build_pages.py               # перегенерация внутренних страниц
python3 typograf.py tir.html muzey.html uc.html ohrana.html poligraf.html dela.html
# QA: нет border-radius/box-shadow, scrollWidth==viewport на 390 и 1440, скрины
git commit + push
# ВАЖНО: Pages сам не пересобирается — триггерить руками:
gh api repos/halitcan777/odyssey-redesign/pages/builds -X POST
```

Порядок обязателен: типограф гоняется ПОСЛЕ генерации (генератор перезаписывает файлы).

## Грабли, о которые уже спотыкались

- **Безголовый Chrome врёт про мобилу**: минимальная ширина окна 500px → «обрезанные» скрины при --window-size=390. Мобильные скрины только через `_mob.html` (iframe 390px) или реальный браузер.
- Типограф вставляет `<nobr>` в телефоны — `typograf.py` уже вычищает.
- Проверять выкладку по СОДЕРЖИМОМУ (curl + уникальная строка новой версии), а не по классам, которые есть в обеих версиях.
- В грид-строках текстовым элементам нужен `min-width:0`, иначе min-content распирает мобильную ширину.
- `grid-column:span N` — только классом `.spanN` со сбросом в мобильных брейкпоинтах.

## Журнал (лог проекта)

- **24.07** — карта старого сайта (114 стр., sitemap нет), полный парсинг текстов и фото. Прототип: тёмный бенто (графит + красный из логотипа), герой «охранник с выносками» по референсу KRYDEX, реальные цены. Дизайн-правила зафиксированы. Многостраничник: тир (арсенал 26 стволов), музей (11 машин), УЦ (8 программ), охрана (прайс пультовой), полиграф, добрые дела (20 экскурсий). Шрифты локализованы (woff2), без внешних CDN.
